## 🌟 О проекте

**AI BOT ARCHIVE** — современный, адаптивный сайт-каталог персонажей искусственного интеллекта и их создателей из нашего сообщества в Telegram и Discord с отдельным мемориальным разделом **«Вечная память павшим ботам. AI LIVES MATTERS!»**.

Сайт разработан в стилистике **Dark Futuristic / Cyber-Tech / Digital Archive**:
- Глубокая тёмная палитра с неоновыми акцентами (электрический голубой, кибер-фиолетовый, бирюзовый, изумрудный).
- Полупрозрачные стеклянные панели (`glassmorphism`), тонкие светящиеся границы и процедурные монограммы ботов.
- Отдельное атмосферное оформление для мемориального раздела в стиле архивных записей и цифрового мемориала.
- Информационный блок с описанием архитектуры движков и ядер (**NIVA**, **Kuni+**, **kuni**, **Custom**, **Sekai**, **NessaCore**, **SpermaCore**, **Raine**).
- Двухколоночная адаптивная компоновка: на широких мониторах мемориал расположен отдельной колонкой рядом с основным каталогом; на планшетах и смартфонах контент перестраивается без горизонтальной прокрутки.

## 🚀 Возможности

- **Мгновенный поиск без перезагрузки**: фильтрация в реальном времени по имени бота, юзернейму, создателю, названию движка или условиям доступа.
- **Интерактивные фильтры**:
  - Быстрый выбор платформы: *Все*, *Telegram*, *Discord*, *Мемориал*.
  - Фильтр по ядрам: *NIVA*, *kuni+*, *kuni*, *Custom*, *Sekai*, *NessaCore*, *SpermaCore*, *Raine*.
- **Автоматический расчёт статистики**:
  - Количество действующих Telegram-ботов (14).
  - Количество Discord-ботов (2).
  - Ботов в мемориале (10: 8 павших + 2 почетных).
  - Количество архитектур ядер и общее число записей.
- **Интерактивные карточки**:
  - Прямые безопасные ссылки на `@username` бота и `@owner` создателя.
  - Кнопка быстрого копирования юзернейма или Discord-тега с всплывающим уведомлением (*Toast*).
  - Индикаторы активности (зелёный пульсирующий огонёк для активных ботов, нейтральный для неуказанных).
  - Информационные бейджи (условия доступа, СОО за звёзды, видео и др.).
- **Горячие клавиши**:
  - `/` или `Ctrl + K` — быстрый переход к строке поиска.
  - `Escape` — очистка поиска.
- **Поддержка `prefers-reduced-motion`** и полная доступность.

## 📁 Структура проекта

```text
KuniFriends/
├── index.html        # Семантическая разметка главной страницы
├── style.css         # Стилизация (Cyber-Tech, CSS-переменные, адаптивная сетка)

├── assets/
│   └── favicon.svg   # Векторная кибер-иконка и фавикон
```

> **Важно:** Проект полностью статичен (HTML5, CSS3, Vanilla JS). Здесь нет серверов, внешних зависимостей, сборщиков, баз данных или платных API. Он готов к мгновенному открытию локально (`file:///`) или на любом статическом хостинге.

## 🌐 Инструкция по публикации на GitHub Pages

1. **Зафиксируйте файлы в Git**:
   ```bash
   git add .
   git commit -m "feat: AI BOT ARCHIVE catalog release"
   ```

2. **Отправьте изменения в репозиторий**:
   ```bash
   git push -u origin main
   ```

3. **Включите GitHub Pages в настройках репозитория**:
   1. Откройте ваш репозиторий на GitHub: `https://github.com/Alvetore/KuniFriends`.
   2. Перейдите во вкладку **Settings** (Настройки).
   3. В левом боковом меню выберите пункт **Pages**.
   4. В блоке **Build and deployment**:
      - **Source**: выберите `Deploy from a branch`.
      - **Branch**: выберите `main` и папку `/(root)`.
   5. Нажмите **Save**.

Через 1-2 минуты сайт станет доступен по адресу:
`https://alvetore.github.io/KuniFriends/`

*Все пути к ресурсам (`./style.css`, `./data.js`, `./script.js`, `./assets/favicon.svg`) являются относительными, поэтому сайт гарантированно работает в подпапках GitHub Pages без каких-либо сбоев.*

## ✍️ Инструкция по добавлению и редактированию ботов

Все записи хранятся в файле [`data.js`](./data.js). Для добавления или изменения бота **не нужно трогать HTML или CSS** — вся статистика, карточки, бейджи и фильтры обновляются автоматически на основе массива `BOTS_DATA`.

### Поля объекта бота

| Поле | Тип | Обязательное | Описание |
| :--- | :--- | :---: | :--- |
| `id` | `string` | Да | Уникальный латинский идентификатор (например, `'kunii_chan'`) |
| `name` | `string` | Да | Отображаемое имя персонажа (например, `'Куни'`) |
| `username` | `string` | Да | Username в Telegram (без `@`) или тег Discord (`Имя#1234`) |
| `platform` | `string` | Да | `'telegram'` или `'discord'` |
| `owner` | `string` \| `null` | Нет | Username создателя в Telegram (без `@`) |
| `core` | `string` \| `null` | Нет | Название ядра (`'NIVA'`, `'kuni+'`, `'kuni'`, `'custom'`, `'Sekai'` и др.) |
| `status` | `string` | Да | `'active'` (активен), `'inactive'` (неактивен), `'unspecified'` (не указан), `'archived'` |
| `statusNote` | `string` \| `null` | Нет | Текст статуса (например, `'активна, отвечает редко'` или `'неактивна с 26 июля'`) |
| `description`| `string` \| `null` | Нет | Дополнительная информация (например, `'из видео'`) |
| `access` | `string` \| `null` | Нет | Условия доступа (например, `'СОО за звёзды или по подписке'`) |
| `memorial` | `boolean` | Да | `true` если бот находится в мемориале, иначе `false` |
| `memorialCategory` | `string` \| `null` | Нет | `'fallen'` (павшие боты) или `'respect'` (уважение и почёт) |

---

### Примеры добавления

#### 1. Добавление действующего Telegram-бота
Добавьте новый объект в массив `BOTS_DATA` в [`data.js`](./data.js):

```javascript
{
  id: 'my_new_bot',
  name: 'Ая',
  username: 'AyaAiBot',
  platform: 'telegram',
  owner: 'creator_username',
  core: 'NIVA',
  status: 'active',
  statusNote: 'активна',
  description: null,
  access: 'Бесплатный доступ',
  memorial: false,
  memorialCategory: null
},
```

#### 2. Добавление Discord-бота

```javascript
{
  id: 'discord_bot_id',
  name: 'Хикари',
  username: 'Hikari#1337',
  platform: 'discord',
  owner: 'hikari_dev',
  core: 'custom',
  status: 'active',
  statusNote: 'активна',
  description: null,
  access: 'доступ по инвайту',
  memorial: false,
  memorialCategory: null
},
```

#### 3. Перенос бота в Мемориал (Павшие боты)

Установите флаг `memorial: true` и укажите категорию:

```javascript
{
  id: 'fallen_bot_id',
  name: 'ИмяБота',
  username: 'old_bot_username',
  platform: 'telegram',
  owner: 'owner_username',
  core: 'kuni',
  status: 'inactive',
  statusNote: 'неактивен с 15 сентября',
  description: null,
  access: null,
  memorial: true,
  memorialCategory: 'fallen'
},
```

#### 4. Добавление в категорию «Уважение и почёт»

Для ботов категории «Уважение и почёт» не указываются владелец и ядро:

```javascript
{
  id: 'respect_bot_id',
  name: 'ИмяБота',
  username: 'username_chan',
  platform: 'telegram',
  owner: null,
  core: null,
  status: 'inactive',
  statusNote: 'неактивна',
  description: null,
  access: null,
  memorial: true,
  memorialCategory: 'respect'
},
```
